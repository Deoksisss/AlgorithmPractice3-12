# Аудит визуализаций

Исходная версия: `298450b812bd459b883235950cea281b06e8c3e8`.

## Архитектура до изменений

Avalonia 11.1 / .NET 8. Представления реализованы в code-behind, отдельного слоя
ViewModel нет. Сервисы Expression, Infix, Maze формируют модель и снимки шагов;
BankView и линейные структуры хранят изменяемое состояние прямо в представлении.
DispatcherTimer проигрывает шаги; стили анимируют Canvas.Left/Top, Opacity и цвет.
Список отдельно интерполирует координаты через Stopwatch. Сервисы консольного
проекта не используются визуализатором, поэтому его self-test не покрывает UI.

## Обнаруженные проблемы и способ исправления

| Компонент | Проблема | Исправление |
|---|---|---|
| Все канвы | Нет общего Fit/Zoom/Pan; большие структуры уходят за экран | Общий SceneViewport с независимой системой координат |
| Стек | Высота не уменьшается; Push задаёт начальную и конечную позицию в одном кадре; Pop пересекается со следующим узлом | Размер по содержимому; общая анимация; отдельная полоса удаления |
| Обе очереди | Только горизонтальная прокрутка; нет Tail и связей; удаление накладывается на сдвиг | Общая навигация, маркировка концов, стрелки связной очереди, отдельная полоса удаления |
| Инфикс | Каждый кадр пересоздаёт токены; несколько извлечений скрыты одним шагом; Build не останавливает таймер; запуск использует старый ввод | Стабильные карточки, отдельные шаги извлечения, анимация переноса, проверка ввода |
| DFS | Generate оставляет старые кадры; resize стирает состояния; размер не учитывает зазоры | Очистка воспроизведения, постоянная геометрия и viewport, восстановление состояний |
| Банк | Фиксированные координаты; обслуженные клиенты перекрываются; отложенный cleanup переживает сброс | Общая навигация, отдельные траектории, отслеживаемая очистка |
| Дерево | ClipToBounds обрезает широкие/глубокие деревья; resize стирает обход | Размер по модели, viewport без пересоздания при resize |
| LRU | Показывает конечный кэш на каждом промежуточном шаге; нет порядка MRU/LRU | Снимок кэша в каждом шаге, видимый порядок записей |
| Все операции списка | Вообще нет стрелок; узлы пересекаются при перестановке; повторный запуск прерывает движение | Связи по текущим координатам, разнесённые траектории, блокировка до конца операции |
| Упорядоченная вставка | Не проверяется предусловие сортировки | Проверка без изменения исходного списка |
| Жизненный цикл | Таймеры продолжают работать у скрытых страниц | Остановка по effective visibility / detach |

План проверки: сборка; регрессионные проверки моделей, шагов, геометрии и UI;
ручной запуск в Linux desktop; пустые/одиночные/большие структуры; resize,
масштабирование, сброс и переключение разделов во время анимации.
