# Результат доработки визуализатора

## Исправления

- Все семь представлений используют общую навигацию: автоматическое вписывание,
  кнопки масштаба, 1:1, Ctrl + колесо, перетаскивание. Масштаб не меняет координаты
  алгоритма. Ручной масштаб сохраняется при изменении размера окна.
- При ширине страницы меньше 1000 лог/легенда/статистика переносятся вниз;
  панели ввода и вспомогательные сведения прокручиваются в своих областях.
- Стек: последовательные фазы сдвига и входа/выхода карточки, сохранение указателя
  вершины при сбросе, уменьшение канвы после удаления.
- Обе очереди: HEAD/TAIL, связи связной реализации, отдельная полоса входа/выхода,
  совпадающий FIFO-порядок, корректные размеры после сброса.
- Инфикс: идентичность каждого токена сохраняется; чтение, Push и каждое Pop
  представлены отдельными шагами. Карточки перемещаются между тремя областями.
  Построение останавливает старое воспроизведение; старт учитывает изменённый ввод.
- DFS: генерация отменяет старые кадры; перерисовка сохраняет подсветку. Снимок
  стека после Pop согласован с удалённой клеткой и новой вершиной; итоговый путь
  имеет отдельное состояние. Улучшена различимость стен и проходов.
- Банк: отдельные зоны ожидающих, обслуживаемого и уходящих клиентов; уборка
  карточек отслеживается при сбросе. Начало следующего обслуживания перенесено
  на правильную минутную границу: три клиента с обслуживанием по минуте,
  прибывшие в 0, ожидают 0, 1 и 2 минуты.
- Дерево: канва учитывает всю глубину и ширину; resize не пересоздаёт узлы и
  подсветку. Связи заканчиваются на границах узлов. LRU отображает снимок именно
  текущего шага, включая MRU → LRU, попадания, промахи и вытеснения. Отмена не
  прогревает кэш результатами ещё не показанных шагов.
- Списки: проверены все девять действий интерфейса, соответствующие восьми
  заданиям (перенос первого/последнего — два действия). Добавлены стрелки,
  раздельные траектории перестановок и удалений, защита от повторного запуска
  во время движения, проверка сортировки перед упорядоченной вставкой.
- Тёмная тема задана явно. На Linux используется доступный TrueType-шрифт
  DejaVu Sans; на других ОС сохранён системный выбор Avalonia. Длинные значения
  обрезаются внутри карточек с полным значением в подсказке. На жёлтых карточках
  используется тёмный текст.

## Архитектура

Сохранены Avalonia 11.1.0, .NET 8, существующее разделение Services/Models/Views
и code-behind. Новые компоненты в `Controls/`:

- `SceneViewport` — преобразование сцены, масштаб и навигация;
- `SceneMotion` — один таймер интерполяции на сцену, последовательные фазы,
  завершение прерванной операции перед следующей;
- `LinkLayer` — стрелки по фактическим координатам движущихся карточек;
- `ResponsiveColumns` — перенос вспомогательной панели при узком окне.

Сервисы добавляют идентификаторы токенов и снимки LRU в данные шагов.
Алгоритмы консольного проекта не менялись. Новая зависимость
`Avalonia.Headless 11.1.0` используется только отдельным тестовым проектом;
зависимости самого приложения не расширены.

## Автоматические проверки

Из корня репозитория:

```sh
dotnet build DataStructuresVisualizer/DataStructuresVisualizer.csproj -c Release
dotnet run --project DataStructuresVisualizer/Tests/Visualizer.Tests.csproj
dotnet run -- --self-test
dotnet run -- --linked-list-test
```

Регрессионный исполняемый тестовый проект проверяет поведение настоящих Avalonia
представлений в headless-режиме, а не только вычислительные сервисы. Он завершается
ненулевым кодом при ошибке. Проверены:

- 60 элементов стека и обеих очередей, пустые операции, порядок и сброс;
- все операции списка, пустые/одиночные списки, отсутствующие значения,
  неправильный порядок для InsertSorted;
- отсутствие пересечения 80 карточек в промежуточной фазе переворота;
- выражения из 100 операндов, отдельные переносы токенов, уникальность их ID;
- дерево глубиной 60 уровней, результат вычисления, cache hit/eviction/restore,
  отсутствие преждевременного изменения живого кэша;
- достижимый/недостижимый лабиринт, восстановление подсветки, согласованность Pop;
- 480 минут банковской смены, баланс занятости/простоя, минутные границы,
  сброс с ожидающей отложенной очисткой;
- Fit для сцены 12000×6000, resize и сохранение ручного масштаба.

Последний успешный прогон: **5176 утверждений**. Консольные `--self-test` и
`--linked-list-test` прошли. Release-сборка завершилась успешно: **0 ошибок,
0 предупреждений**. `git diff --check` не обнаружил проблем с пробелами.

## Проверка в настоящем окне

Linux/X11, .NET 8 runtime, SDK 10; приложение запущено и просмотрено через
`cloud-desktop`. Проверены все семь представлений: набор операций стека,
инфиксное преобразование, обе очереди, DFS со стеком/тупиками, банк с тремя
одновременно прибывшими клиентами, вычисление `(2+3)*(2+3)` с результатом 25
и попаданием в кэш, переворот списка. Проверены промежуточные состояния
списка, масштаб дерева 156%, Pan, 1:1 и Fit. Размер окна менялся; при минимальном
клиентском размере 1020×620 элементы управления доступны через прокрутку,
а сцена вписывается целиком. Тёмный текст на жёлтой подсветке проверен в окне.

## Границы проверки

- Windows и macOS отдельно не запускались.
- Миллионные EXTREME-наборы консольной диагностики пропущены штатным режимом
  `--self-test`; они не используются штатным импортом визуализатора.
- Виртуализация не добавлена: большие структуры целиком существуют в памяти.
  В режиме Fit на очень большой структуре подписи закономерно уменьшаются;
  для чтения отдельных узлов предназначены Zoom/1:1, Pan и подсказки.
- Ручная проверка охватывает перечисленные сценарии, а не все возможные
  последовательности ввода, кадры и системные масштабы DPI. Headless-тесты
  проверяют модели, геометрию и жизненный цикл; они не заменяют оценку рендера
  на каждой поддерживаемой ОС.
- Поддерживаемая грамматика инфиксного визуализатора сохранена: числа, скобки
  и бинарные `+ - * /`. Расширения консольного конвертера сюда не переносились.

Push в удалённый репозиторий не выполнялся.
